# 1. 两数之和

## 题目目标

给定整数数组 `nums` 和目标值 `target`，找出和为 `target` 的两个元素下标。每个输入只有一个答案，同一元素不能重复使用。

## 核心思路

遍历数组时，用哈希表保存已经见过的“数值 → 下标”。对于当前位置 `i`：

1. 计算补数 `need = target - nums[i]`。
2. 在哈希表中查找 `need`。
3. 找到就返回补数下标和当前下标。
4. 未找到才把当前值与下标写入哈希表。

先查询、后插入可以避免同一个元素与自己配对。

## C++17 代码

```cpp
#include <unordered_map>
#include <vector>

using std::unordered_map;
using std::vector;

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> indexByValue;

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            const int need = target - nums[i];
            const auto it = indexByValue.find(need);

            if (it != indexByValue.end()) {
                return {it->second, i};
            }

            indexByValue[nums[i]] = i;
        }

        return {};
    }
};
```

## 复杂度

- 时间复杂度：平均 `O(n)`。
- 空间复杂度：`O(n)`。

## 易错点

- 不要先插入再查询，否则当 `target == 2 * nums[i]` 时可能错误地重复使用当前元素。
- 哈希表保存的是数组值对应的下标，不是补数对应的下标。
- `unordered_map::find` 不会插入键；`operator[]` 在键不存在时会插入默认值。
- 返回的是下标而不是元素值。
