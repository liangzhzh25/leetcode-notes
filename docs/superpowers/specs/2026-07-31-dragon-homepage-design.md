# Dragon-themed LeetCode Homepage Design

## Goal

Turn the Quartz index page into a cinematic, colorful entry point for the LeetCode notes while keeping article pages clean and readable.

## Approved direction

- Use the user-provided anime image as a wide homepage hero.
- Use the “movie banner + content entry cards” layout.
- Hero copy: “在龙与代码之间，寻找问题的唯一解。”
- Show four direct entry cards: 两数之和、移动零、C++ 哈希表速查、vector 删除操作.
- Apply the visual treatment only to `body[data-slug="index"]`.
- Preserve Quartz search, dark mode, explorer, graph, and article layouts.
- On narrow screens, crop the image around its central subject and stack cards in one column.

## Files

- `default-index.md`: canonical homepage content regenerated by the sync script.
- `content/index.md`: currently published homepage content.
- `quartz/styles/custom.scss`: homepage-only responsive styles.
- `quartz/static/dragon-hero.webp`: optimized hero image.

## Verification

- Local Quartz build exits successfully.
- Generated `public/index.html` contains the hero and four links.
- Generated article pages do not contain the homepage hero.
- Hero image is emitted under `public/static/`.
- GitHub Actions deploys the pushed commit successfully.
- Online homepage returns HTTP 200 and contains the new hero copy and entry links.
